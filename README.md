# Minion Banana Run 

## Запуск
Откройте папку `minion-banana-run` в VS Code и запустите `index.html` через Live Server. Не открывайте через `file://` — используются ES-модули.

## Что реализовано
- 5 длинных уровней с камерой, индивидуальными фонами из предоставленных изображений, 12 платформами, опасностями и финишем.
- Обычные бананы +100 очков, золотой банан +500 (высоко над платформой). Для прохождения требуется собрать все бананы, включая золотой.
- Прыжок только с опоры, гравитация, столкновения, пауза при скрытии вкладки, один `requestAnimationFrame` цикл, `dt`.
- Синтезированная мелодия и звуки прыжка, сбора, победы/поражения через Web Audio API. Звуки запускаются после нажатия «Играть» из-за ограничений браузеров; это оригинальные игровые эффекты, не записи голосов актёров.
- Управление: ← → / A D, Space / W / ↑; экранные кнопки для телефона.
- Рекорд через `localStorage`, кнопки старт, пауза, заново, звук.

## Файлы
`index.html` — интерфейс; `style.css` — оформление; `js/main.js` — события; `js/game.js` — цикл, камера, правила; `js/player.js` — физика и персонаж; `js/levels.js` — уровни; `js/audio.js` — музыка и эффекты; `assets/` — фоны.



## Обновление 3
- Пять разных карт с отдельной геометрией, препятствиями и расположением бананов.
- После прохождения уровня следующий сохраняется в localStorage (`minionBananaCheckpoint`). При поражении и при повторном открытии игры появляется выбор: с первого уровня или с сохранённого. Кнопка «Заново» сбрасывает прогресс.
- `assets/jump.mp3` — пользовательский звук прыжка из `бидо.mov`.
- `assets/music.mp3` — пользовательская фоновая песня из `minony-banan423.mp3`, играет тихо и по кругу.
- Браузер разрешает музыку после первого нажатия на кнопку запуска игры.


## Изменения версии 4
- Первый уровень и его платформы сохранены.
- На уровнях 2–5 добавлены парящие платформы и отдельные бананы.
- Палитра платформ зависит от фона уровня.
- В третьем уровне надписи внутри Canvas белые.
- Фоновая песня заменена пользовательским файлом «банана.mov», конвертированным в MP3.
- Прыжок по-прежнему озвучен файлом «бидо.mov».
- Шрифт Fredoka подключается из Google Fonts (для загрузки нужен интернет); это близкая стилистическая альтернатива шрифту на референсе.


### Исправление доступности платформ (v4.1)
На уровнях 2–5 парящие платформы опущены до достижимой высоты (68–84 px над опорой). Золотые бананы над ними тоже опущены. Первый уровень не изменён.
